# Exemplo de execucao — FarmTech Notebooks

Esta pasta mostra onde ficariam os arquivos executaveis de uma task em grupo.

Os notebooks reais foram omitidos para manter o template leve e sem dados de aluno. Use os arquivos em `specs/examples/farmtech-notebooks/` para entender o fluxo.

## Estrutura esperada em uma task real

```text
tasks/taskNN_nome/
  data/
  parte1_exploracao.ipynb
  parte2_descritiva.ipynb
  parte3_perfis.ipynb
  parte4_modelos.ipynb
  README.md
```
