# Plano — FarmTech Notebooks

## Etapas

- [ ] Coordenador cola o enunciado completo e ajusta `SPEC.md`.
- [ ] Grupo confirma `SPLIT.md`.
- [ ] Cada membro cria sua branch.
- [ ] Cada membro implementa o notebook da sua parte.
- [ ] Integrador revisa PRs e monta README.
- [ ] Revisor preenche `REVIEW.md`.
- [ ] Grupo grava video e submete no portal.

## Comandos base

```bash
python -m venv .venv
source .venv/bin/activate
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
jupyter notebook
```
