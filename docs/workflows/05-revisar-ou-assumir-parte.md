# Workflow 05 — Revisar ou assumir parte de outro membro

Use quando o aluno precisa ajudar o grupo revisando uma parte alheia ou assumindo uma entrega que ficou para tras.

## Objetivo

Permitir socorro ao grupo sem apagar autoria, contexto ou combinados.

## Revisar parte de outro

1. Ler `SPEC.md`, `SPLIT.md`, `WORKPLAN.md` e a branch/arquivos do colega.
2. Comparar a entrega com os requisitos.
3. Apontar problemas em ordem de impacto:
   - requisito faltando;
   - erro tecnico;
   - incoerencia com outras partes;
   - falta de evidencia/teste;
   - melhoria de clareza.
4. Sugerir correcoes pequenas e verificaveis.
5. Nao reescrever a parte do colega sem pedido explicito.

## Assumir parte de outro

1. Registrar transferencia em `SPLIT.md`.
2. Criar nova branch ou continuar branch combinada.
3. Atualizar `WORKPLAN.md` com novo responsavel.
4. Implementar o minimo necessario para cumprir a spec.
5. Registrar no PR que houve transferencia.

## Saidas esperadas

- Comentarios de revisao, ou
- `SPLIT.md` atualizado com transferencia, e
- PR/branch com nova entrega.
