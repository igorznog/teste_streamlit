# Workflow 04 — Fazer minha parte

Use quando o aluno ja sabe sua responsabilidade dentro de uma task em grupo.

## Objetivo

Focar a IA no escopo do aluno, evitando que ela tente refazer o trabalho inteiro.

## Passo a passo

1. Ler `TASK_REGISTRY.md`, `GROUP.md`, `LOCAL.md` e `specs/taskNN_nome/SPLIT.md`.
2. Identificar o aluno em `LOCAL.md`.
3. Encontrar a parte correspondente no `SPLIT.md`.
4. Confirmar com o aluno: “Vou trabalhar somente na parte [Px]. Correto?”
5. Criar/usar a branch indicada.
6. Implementar apenas os arquivos/pastas da parte.
7. Atualizar evidencias e status da parte em `SPLIT.md` ou `WORKPLAN.md`.
8. Preparar PR usando [pull-request-template.md](../templates/pull-request-template.md).

## Se a parte nao estiver clara

Pedir ao aluno uma destas decisoes:

- ajustar `SPLIT.md`;
- pedir ao coordenador do grupo;
- assumir uma parte ainda sem dono;
- transformar a task em solo.

## Saidas esperadas

- Arquivos da parte do aluno.
- Branch pronta para PR.
- Descricao de PR com como validar.
