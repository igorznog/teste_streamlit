# Workflow 07 — Entrega final FIAP

Use quando o codigo, notebook, relatorio ou dashboard ja esta pronto e falta empacotar para a plataforma.

## Objetivo

Evitar perder pontos por detalhes de entrega: formato, video, link, ZIP, README ou arquivo errado.

## Passo a passo

1. Ler `SPEC.md`, `INTEGRATION.md`, `REVIEW.md` e `TASK_REGISTRY.md`.
2. Conferir formato exigido:
   - repo GitHub;
   - ZIP;
   - PDF;
   - notebook;
   - dashboard;
   - video;
   - link no portal.
3. Rodar validacoes finais.
4. Atualizar README/manual.
5. Preparar roteiro de video com [`video-script.md`](../templates/video-script.md), se necessario.
6. Gerar ZIP somente com arquivos relevantes.
7. Conferir [`SAFETY_PII_COPYRIGHT_CHECKLIST.md`](../templates/SAFETY_PII_COPYRIGHT_CHECKLIST.md).
8. Registrar pendencias humanas no `TASK_REGISTRY.md`.

## Checklist pre-upload

- [ ] Arquivo correto selecionado.
- [ ] Link do repo/video funciona.
- [ ] Video esta como nao listado quando pedido.
- [ ] Nome/RM/grupo aparecem quando exigido.
- [ ] Ultima versao esta na branch/commit correto.
- [ ] Prazo confirmado.
- [ ] Checklist de seguranca/PII/copyright revisado.

## Regra

O assistente pode preparar tudo, mas o aluno deve conferir e fazer o upload final na plataforma FIAP.
