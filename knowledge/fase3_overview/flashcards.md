# Flashcards — Fase 3 Overview

### Q1
**P:** Quais são as 6 disciplinas da Fase 3 do 1TIAOA?
**R:** AI Challenges, Python (Numpy/Pandas/Matplotlib/Seaborn), Statistical Computing with R, Cognitive Data Science, Machine Learning & Modelling, Formação Social.

### Q2
**P:** Qual é a disciplina **nova** da Fase 3 (não existia nas fases anteriores)?
**R:** Cognitive Data Science — ensina modelagem de banco de dados.

### Q3
**P:** Quais quatro tipos de filtro de sinal são cobrados em AI Challenges?
**R:** Passa-baixa, passa-alta, passa-faixa e rejeita-faixa.

### Q4
**P:** Quais são as duas técnicas de cluster cobradas em Statistical Computing with R?
**R:** k-means e cluster hierárquico.

### Q5
**P:** Verdadeiro ou falso: na Fase 3 já se implementa um modelo de Machine Learning aplicado completo.
**R:** Falso. A Fase 3 só **introduz** o aprendizado supervisionado (classificação). A aplicação aprofundada vem nas próximas fases.

### Q6
**P:** Cluster (k-means/hierárquico) é aprendizado supervisionado ou não supervisionado?
**R:** Não supervisionado. Já classificação (que entra em ML & Modelling) é supervisionada.

### Q7
**P:** Qual é o entregável físico/integrador central da Fase 3 da FarmTech Solutions?
**R:** Sistema físico de irrigação inteligente para lavoura, com armazenamento dos dados em banco SQL.

### Q8
**P:** Quais bibliotecas Python são introduzidas/aprofundadas na Fase 3 e para que servem?
**R:** Numpy (arrays e álgebra linear), Pandas (DataFrames — importar/limpar/agrupar/juntar), Matplotlib + Seaborn (visualização e gráficos estatísticos).

### Q9
**P:** Qual o papel da disciplina Formação Social no projeto da FarmTech?
**R:** Conectar tecnologia a gestão estratégica, sustentabilidade e uso eficiente de recursos hídricos e energéticos — alinhada ao projeto de irrigação.

### Q10
**P:** Por que sensores são tratados como "pilar" em AI Challenges?
**R:** Porque são a interface entre o mundo físico e os sistemas digitais — capturam os dados que alimentam os algoritmos de IA. Sem sinal limpo (filtragem) não há dado útil.
