# LGPD e Tipos de Inteligência Artificial
**Disciplina**: AI Challenges | **Aula**: 02 (parte 2/3) | **Fase**: 1

## LGPD e IA
A LGPD (Lei Geral de Proteção de Dados, 2018, vigente desde **setembro 2020**) não trata especificamente de IA, mas impacta diretamente seu uso. Princípios que afetam IA:

| Princípio LGPD | Impacto na IA |
|---|---|
| Transparência | Sistema deve explicar como usa os dados |
| Consentimento | Precisa de autorização do titular |
| Finalidade | Dados só para o propósito declarado |
| Minimização | Coletar apenas o necessário |
| Segurança | Proteger contra acessos não autorizados |
| Responsabilidade | Organização responde pelo uso da IA |

Pontos críticos: viés algorítmico viola princípio de justiça; falta de explicabilidade viola transparência; dados de treino massivos podem violar minimização.

## IA Fraca vs IA Forte

| | IA Fraca (Estreita) | IA Forte (Geral) |
|---|---|---|
| **Objetivo** | Simula inteligência | Possui inteligência |
| **Foco** | Tarefas específicas | Ampla gama de tarefas |
| **Autoconsciência** | Ausente | Presente |
| **Raciocínio** | Simulado | Autônomo |
| **Exemplos** | Siri, Alexa, Tesla, diagnóstico médico | **Não existem exemplos reais** |

IA Forte é **conceito teórico** — ninguém conseguiu criar ainda. Desafio: nem sabemos totalmente como o cérebro humano funciona.

## 5 Tipos de IA (por técnica)
1. **Machine Learning (ML)**: aprende com dados sem ser programado explicitamente. Tipos: supervisionado, não supervisionado, por reforço. Ex: filtros de spam, recomendações, motores de busca.
2. **Redes Neurais Artificiais (ANNs)**: equações matemáticas inspiradas no cérebro. Subtipos: CNN (imagens), RNN (dados sequenciais). Ex: reconhecimento facial, tradução, diagnóstico médico.
3. **Processamento de Linguagem Natural (NLP)**: computadores entendem/geram linguagem humana. Ex: chatbots, Siri/Alexa, tradução automática.
4. **Visão Computacional**: computadores "veem" e interpretam imagens/vídeos. Ex: carros autônomos, controle de qualidade, reconhecimento facial.
5. **Robótica**: IA + engenharia → máquinas autônomas. Ex: robôs industriais, cirúrgicos (Da Vinci), domésticos.

## Pegadinhas de prova
- **IA Forte NÃO existe** na prática. Qualquer exemplo real (Alexa, Tesla, ChatGPT) é IA **Fraca**.
- LGPD é de **2018**, vigente desde **setembro de 2020** — não confundir as datas.
- LGPD não proíbe IA, mas exige conformidade com seus princípios.
- CNN é para **imagens**, RNN é para **dados sequenciais** (texto, séries temporais) — não trocar.
- Robô Da Vinci é **colaborativo** (trabalha com humanos). Robôs industriais **NÃO** são colaborativos (perigosos).
