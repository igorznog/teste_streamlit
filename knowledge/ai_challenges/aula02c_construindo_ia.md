# Construindo sua Própria IA — Plataformas, APIs e Ferramentas
**Disciplina**: AI Challenges | **Aula**: 02 (parte 3/3) | **Fase**: 1

## Conceito-chave
Democratização da IA: hoje qualquer pessoa pode criar sistemas inteligentes sem saber programar, usando plataformas **low-code/no-code**. Mas têm limitações: complexidade restrita, flexibilidade limitada, dependência da plataforma.

## Plataformas Low-Code / No-Code
| Plataforma | O que faz |
|---|---|
| **Bubble** | Apps web completos sem código (arrastar e soltar) |
| **Adalo** | Apps móveis sem código, integra APIs de IA |
| **AppSheet** | Apps móveis/web do Google, até 10 usuários grátis |
| **Voiceflow** | Interfaces conversacionais (chatbots de voz) |
| **RunwayML** | Edição de vídeo/imagem com IA |
| **Microsoft Power Automate** | Automação de tarefas e workflows |
| **Zoho Creator** | Apps de negócios (low-code, pago) |

## Frameworks de Desenvolvimento (para quem programa)
| Framework | Foco | Destaque |
|---|---|---|
| **TensorFlow** | ML e Deep Learning | Google, robusto, escalável |
| **PyTorch** | Deep Learning e pesquisa | Sintaxe pythônica, flexível |
| **Scikit-learn** | ML tradicional | Simples, ótimo para iniciantes |
| **Keras** | Deep Learning (alto nível) | API sobre TensorFlow/PyTorch |

## APIs Pré-construídas
Blocos prontos para integrar IA sem desenvolver do zero:
- **Amazon Rekognition**: reconhecimento de imagens e faces
- **IBM Watson Assistant**: chatbots e interfaces conversacionais
- **Azure Text Analytics**: análise de texto e sentimento

## Ferramentas de Análise de Dados
**Tableau**, **Power BI**, **Qlik Sense**, **Google Data Studio** — dashboards e BI com IA embutida para análise preditiva.

## Ferramentas NLG (Geração de Linguagem Natural)
**Gemini** (Google), **GPT-3/4** (OpenAI), **Jasper** (marketing), **Writesonic** (conteúdo geral).

## Ferramentas de IA Gratuitas (para praticar)
| Ferramenta | Prática sugerida |
|---|---|
| **ChatGPT** | Gerar código Python, calibrar prompts |
| **Teachable Machine** | Treinar modelo de classificação (imagem/som/pose) sem código |
| **Replit** | Testar código gerado por IA online |

## Pegadinhas de prova
- Low-code ≠ No-code: low-code exige algum código; no-code é 100% visual.
- TensorFlow é do **Google**, PyTorch é do **Meta/Facebook** — não trocar.
- Keras não é independente: é uma API de alto nível que roda **sobre** TensorFlow ou PyTorch.
- Teachable Machine é do **Google** e funciona no **navegador** (não precisa instalar nada).
- Plataformas no-code têm **limitações**: não servem para IA complexa ou de alto desempenho.
